## 📖 Sobre o Projeto

Base de Conhecimento é uma aplicação web interativa que apresenta informações detalhadas sobre diversas linguagens de programação. O projeto oferece uma interface elegante e intuitiva para explorar características, paradigmas, casos de uso e níveis de dificuldade de mais de 20 linguagens de programação populares.

## ✨ Funcionalidades

- 🔍 **Busca Inteligente**: Pesquise linguagens por nome, ano, descrição, paradigma, uso comum ou nível de dificuldade
- 📱 **Design Responsivo**: Interface adaptável para diferentes tamanhos de tela
- 🎨 **Interface Moderna**: Design minimalista com tema escuro e animações suaves
- 📊 **Informações Detalhadas**: Cada linguagem apresenta:
  - Nome e logo oficial
  - Ano de criação
  - Descrição completa
  - Paradigma de programação
  - Casos de uso comum
  - Nível de dificuldade

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página
- **CSS3**: Estilização com variáveis CSS, Flexbox e animações
- **JavaScript**: Funcionalidade de busca e renderização dinâmica
- **JSON**: Armazenamento de dados das linguagens

## 💻 Linguagens Disponíveis

O projeto contém informações sobre as seguintes linguagens:

## 🚀 Como Usar

1. Acesse o site através do [GitHub Pages](https://leolafa.github.io/alura/)
2. Todas as linguagens são exibidas automaticamente ao carregar a página
3. Use a barra de busca no topo para filtrar linguagens específicas
4. Digite qualquer termo relacionado (nome, ano, paradigma, etc.) e clique em "Buscar"
5. Os resultados serão filtrados em tempo real

## 🎯 Como Executar Localmente

1. Clone este repositório:
```bash
git clone https://github.com/leolafa/alura.git
```

2. Navegue até o diretório do projeto:
```bash
cd alura
```

3. Abra o arquivo `index.html` em seu navegador preferido ou use um servidor local:
```bash
# Usando Python 3
python -m http.server 8000

# Usando Node.js (http-server)
npx http-server
```

4. Acesse `http://localhost:8000` no seu navegador
